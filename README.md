# Parvathi Nalla — Portfolio Website

An original, responsive, recruiter-friendly engineering portfolio built as a **zero-dependency static website**. No build tools, API keys, external font downloads, cookies, analytics, or tracking scripts required.

## Getting started

Double-click `index.html` or start a local server:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Publishing

This repository is published on GitHub Pages at:
👉 **`https://parvathinalla.github.io/`**

Deployed from the `main` branch root. All local assets, styles, project case studies, and resume PDFs are bundled as a zero-dependency static site.

## Recruiter experience

- Scannable headline and clickable resume
- Clear projects, metrics, engineering experience, and research
- Dedicated case-study pages with source links and honest evaluation statements
- Semantic sections, keyboard navigation, mobile menu, accessible focus, reduced-motion support
- Social sharing image, favicon, structured data, sitemap-ready static structure
- No external scripts or tracking
